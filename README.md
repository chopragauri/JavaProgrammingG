## 📌 About

This repository contains my complete Java programming coursework — organized into **lab experiments** (weekly sessions) and **module assignments** (topic-wise problem sets). It demonstrates hands-on practice across all major Java pillars: OOP design, the Collections framework, Generics, and concurrent programming.

## 🚀 How to Run

**Prerequisites:** Java 8+ and IntelliJ IDEA (or any Java IDE)

```bash
# Clone the repository
git clone https://github.com/chopragauri/JavaProgrammingG.git

# Navigate to the src directory
cd JavaProgrammingG/src

# Compile any file
javac FileName.java

# Run
java FileName
```
